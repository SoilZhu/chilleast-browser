# ChillEast Web · 文案规范（本次改版基线）

> 目标：界面文案像**成熟商业产品**（参考 App Store 工具类 App 的克制语气），
> 而不是课程作业 README、也不是技术方案汇报。
>
> 参照基准：原版 App 的 l10n 文案 —— `/home/soilzhu/code/chilleast/lib/l10n/app_zh.arb`。
> App 的文案是**短、平、直**的：`暂无通知公告`、`暂时没有待办作业`、`本学期暂无成绩数据`、
> `暂无符合条件的请假记录`、`点击登录以访问更多功能`。网页版一律向这个密度看齐。

## 1. 硬性字数上限

| 位置 | 上限 | 合格示例 |
|---|---|---|
| 页面标题（h1/h2） | 8 字 | `成绩查询` `报修` `云端同步` |
| 页面副标题（标题下一行） | 16 字 | `本学期已归档课程` |
| 卡片标题 | 8 字 | `校园卡余额` |
| 按钮 | 6 字 | `刷新` `提交` `重新获取` |
| 空状态 | 12 字 | `暂无进行中的预约` |
| 提示 / 错误 | 24 字，且必须说清下一步 | `网络异常，请稍后重试` |
| 长说明（仅登录页、关于页允许） | 60 字 | 见 §8 |

超过上限 = 没改完。

## 2. 必须删除的内容

**① 架构术语**（一个都不许出现在界面上）
零状态、中转、Worker、Cloudflare、AES、GCM、内存加密、自包含、令牌、SSO、Cookie、
LocalStorage、IndexedDB、base64。
> 例外：登录页可保留「统一身份认证」这一个学校官方叫法。

**② 营销词 / 自我表扬**
无缝、极佳、零延迟、直通车、一键、全新、强大、智能、秒开、极致、全方位、
「数据零延迟」「实时连接」「无需重复配置」「备考无忧」。

**③ 内部对照（写给开发者看的）**
与手机端一致、对齐 App、原版、App 端已支持 / Web 端暂未实现、手机端内置资源一致、
「功能分类与成员顺序严格对齐手机端」「分类与手机端 ChillEast 保持一致」。
→ 用户不关心我们怎么实现的，删掉。

**④ 语气词与标点**
`！`、`哦`、`啦`、`呢`、`~`、`……`、`！！`。
加载中一律用单个省略号 `…`（不是三个点也不是六个点）。

**⑤ 写死的统计数字**
`47门汇总`、`12门已出成绩`、`(12门)` 这类硬编码数字一律删除；
由真实数据算出来的数字（`共 3 条`、`第 5 周`）可以保留。

**⑥ 解释性尾句**
「（数据零延迟）」「（原智慧农大/今日校园）」「（后台自动计算并渲染）」这类括注删除。

## 3. 句式规则

- **空状态**：`暂无 + 名词` 或 `还没有 + 名词`。**不写引导语**（禁止「点击上方…开始选座」）。
- **加载中**：`加载中…` `提交中…` `同步中…`。禁止「正在为您…」「请稍候片刻…」。
- **成功**：`已保存` `已提交` `已取消`。禁止「成功！」「大功告成」「已成功将…」。
- **按钮**：动词开头，2–4 字。`保存` `提交` `刷新` `重新获取` `查看全部`。
- **标题**：名词短语，不加动词、不加感叹。
- **说明文字**：能用一句话说完就一句话；能删就删。

## 6. 不要动的东西

- **组件结构、Tailwind 类名、props / emits / 逻辑**：只改**文本内容**。
- 由后端返回、原样展示的字段（课程名、通知标题、宿舍名、错误 `err.message`）：不动。
- `console.error` / `console.warn` 里的调试文案：不动。
- 表单 `<option>` 的 **value**：不动（只改显示文本）。
- 交互流程、跳转、接口调用：不动。
